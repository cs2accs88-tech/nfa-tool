# Steam Manager

A beginner-friendly Electron desktop application scaffold.

## Project structure

- `src/`
  - `main/` - main process code, app lifecycle, window creation
  - `renderer/` - UI files, front-end scripts, styles
  - `config/` - application configuration and constants
  - `data/` - local data storage, cache files, JSON databases
  - `assets/` - images, icons, fonts, static files
  - `utils/` - helper modules and reusable utilities
  - `logs/` - runtime log files
  - `backup/` - backup snapshots and exported data copies
- `tests/` - tests for application logic and integration

## Running the app

1. Install dependencies: `npm install`
2. Start the app: `npm start`
