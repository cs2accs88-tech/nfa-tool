Check All performs a full sign-in for each stored account one at a time (never logging anyone out) and waits for Steam to fully initialize before collecting the account's info. Any token that can't complete sign-in is marked Dead immediately and enrichment is skipped for that account. Steam is switched per account, so this takes a while. Rank, Elo, Prime, VAC and Inventory come from stored data; persona name is refreshed live from Steam. The Accounts tab updates automatically when the scan (or any per-account update) finishes.
